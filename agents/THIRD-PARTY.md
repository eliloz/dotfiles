# Third-party text in this package

## Matt Pocock's skills

Twelve skills under `.agents/skills/` are Matt Pocock's, from
[mattpocock/skills](https://github.com/mattpocock/skills) (MIT): `grill-with-docs`, `domain-modeling`,
`grilling`, `to-spec`, `to-tickets`, `implement`, `code-review`, `tdd`, `codebase-design`, `retro`,
`writing-for-agents` and `setup-matt-pocock-skills`. They were added unchanged in commit b604669.
`setup-matt-pocock-skills` is his trimmed version of the same skill (issue tracker only, without the triage labels
and domain docs parts), as he synced it into his course project
([ai-hero-dev/cohort-005-project](https://github.com/ai-hero-dev/cohort-005-project), commit a2ad725, "Sync skills
from upstream mattpocock/skills 4ae2317"). My changes are separate commits after b604669: `git log -p agents/.agents/skills/<name>`.

The lab's local tracker template (`pi/.pi/agent/extensions/lab/tracker/issue-tracker-local.md`) is his too.
